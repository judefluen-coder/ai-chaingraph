# Published Datasets

This directory is reserved for AI-ChainGraph datasets that are ready for public use.

Published records must:

- use only public, legally redistributable source metadata;
- include stable entity IDs and explicit industry stages;
- include a relationship basis, factual summary, source URL, and verification date;
- exclude paid data-source output, full copyrighted documents, credentials, and personal research notes;
- pass the repository validation commands before merge.

Original structured data published by AI-ChainGraph is licensed under CC BY 4.0. See [DATA_LICENSE.md](../DATA_LICENSE.md). Linked third-party source material remains subject to its owners' terms.

The current repository contains fictional examples only. Real A-share and US datasets will be added here incrementally by industry chain through reviewed data pull requests.
