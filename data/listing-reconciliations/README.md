# A股上市核对清单

这里保存每周对上交所、深交所和北交所新增上市公司的完整核对结果。清单与数据批次分离：即使某家公司不属于当前 AI 产业链本体，也必须以 `excluded` 决策留下记录，避免“没有纳入”和“没有看见”混在一起。

## 文件规则

- 文件名以 `.reconciliation.json` 结尾，且 `review_status` 必须为 `approved`。
- `markets` 固定为 `SH`、`SZ`、`BJ`，每个周期连续覆盖上一清单之后的自然日。
- 每条记录必须使用交易所官方 HTTPS 来源，并给出 `included` 或 `excluded` 决策及原因。
- `included` 记录必须指向已应用的数据批次、发行人、证券，并具备 `security_issued_by` 和至少一条具体产业关系。
- 新清单不得跳过日期，也不得重复核对同一证券。
- 某周期没有新增上市公司时仍应提交连续日期的空 `listings` 数组，证明三家交易所已经核对，而不是静默跳过。

`npm run update:weekly` 会验证全部清单并把核对截止日及纳入/排除统计写入公开快照。`npm run validate:snapshot` 会再次校验清单与快照是否一致，CI 还会拒绝超过 8 天未更新的核对日期。
