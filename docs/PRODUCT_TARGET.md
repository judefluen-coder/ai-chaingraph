# 目标模式：可核验、可比较、可分享的 AI 产业研究工作台

## 本轮目标

服务希望快速理解上市公司产业角色的个人研究者和内容创作者。核心任务是：找到公司 → 比较产业位置与实际动作 → 打开原始证据 → 分享研究入口。不是荐股、实时行情或自动生成投资结论的工具。

## 本轮交付与验收

- 公司详情进入对比，不增加主导航或红点。选择 2–4 家公司，按名称或代码添加、移除，桌面并列、手机纵向阅读。
- 显示具体动作、宽口径及待复核状态、来源日期；支持共同产业位置筛选和返回逐边证据。位置重叠不得表述为商业关系。
- 对比链接使用公开公司 ID，刷新可恢复；不携带个人关注笔记。链接展示接收者打开时的当前快照，不是固定历史版本。
- 每周任务使用工作分支 → PR → 必需 CI → 合并 → Pages → 同提交 Sites → 两端哈希校验。保留未提交和未推送的工作。
- 单元测试覆盖 ID 去重、数量限制、共享位置、失效 ID 和 URL；浏览器覆盖桌面/手机、刷新、证据跳转、移除和关闭。

## 产品边界

没有收录不代表不存在业务；来源级别不等于逐条人工确认；具体关系覆盖率不等于准确率。共同位置不是共同客户或供需合同。历史和更新仍保持深层入口。

本轮不扩张未经核验的公司/关系，不篡改核验日期，不接入第三方行为追踪，不发送宣传内容。新版本部署必须明确通过发布门禁；本地验证不等于上线。

## 下一阶段

只有真实用户反馈支持时再做：关注清单导入与冲突处理、研究图导出、变化摘要订阅。导出图需要同时显示数据日期、证据边界和回到原文的入口。订阅需要单独设计账号、隐私和退订流程，不伪装成静态站现成功能。
