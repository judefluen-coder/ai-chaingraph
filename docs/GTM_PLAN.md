# GTM：用可核验的研究案例获取第一批回访用户

## 定位和假设

一句话：查一家上市公司在 AI 产业链里做什么，并找到判断背后的原始证据。

以下是待验证的实验方案，不是平台流量承诺。第一批面向愿意读公告的个人研究者和产业内容创作者；先验证研究价值，再扩大曝光。

## 四周实验

1. 准备：完成发布验证，挑选三个有完整证据的案例。邀请 10–15 位研究者，每人带一个真实问题；记录任务是否完成、卡点和是否打开原文，不收集个人投资持仓。
2. 观察：请用户独立完成找公司、比较两家公司、找到依据三个任务。优先修复多数人重复遇到的问题，不先加功能。
3. 传播：发布 3–5 篇案例内容，每篇一个问题、一张真实界面图、一个研究链接及来源日期。朋友圈讲个人使用场景；小红书用问题与图解组织；GitHub 保留证据政策、使用边界和贡献入口。发布前人工复核措辞。
4. 复访：询问愿意参与的用户是否再次使用、用于哪个问题、哪里仍需手工处理。根据反馈决定继续、调整定位或停止扩张。

## 三个案例模板

### 同在机器人产业链，做的真的是同一件事吗？

选 2–3 家有不同具体动作的公司，展示“生产什么 / 开发什么 / 提供什么”。必须逐条打开原始披露核对，不能以概念板块标签代替业务证据。配公司对比截图和对应分享链接。

### 使用 AI，不等于生产 AI 产品

使用已有的待复核/更正案例，解释主体、动作、对象的区别。附原句、当前图谱关系和更正历史；不要将待复核记录写成已证实错误。

### 一条关系被撤回之后，证据去哪了？

选已实际发生的撤回，展示当前图谱不再出现该边，但历史保留原始依据及更正原因。不能制作虚构历史来突出产品功能。

## 首发文案草案

我做了一个 AI 产业研究地图：不是只把公司贴上“AI 概念”的标签，而是继续追问，它具体生产、开发或提供什么？依据在哪里？

现在可以把几家上市公司放在一起对比产业位置，再逐条打开原始披露。也会保留关系更正记录。数据仍有覆盖和更新边界，不是实时行情，也不构成投资建议。

最希望你带着一个实际研究问题来试：有没有省下一步找资料的时间？哪里仍然不清楚？

发布时补入经复核的真实案例图和该组公司的对比链接，不只放首页。

## 衡量与隐私

首轮用自愿访谈记录即可，当前未接入行为分析服务。记录参与人数、独立完成任务人数、打开原始证据人数、七天内主动回来的人数及分享带来的有效试用，必须同时写分子分母。样本小，不包装成增长结论。

后续埋点需单独选择服务及隐私方案，仅考虑匿名的打开公司、打开证据、完成对比、分享事件。不上传个人笔记、证券搜索原文或投资信息；不以默认开启追踪换取数据。
